# Part Assignment 3: JavaScript Programming

## Overview

This assignment covers JavaScript functions, arrow functions, control flow, arrays and array methods.

## Task 1: Functions, Arrow Functions & Control Flow

**File:** `task1_functions.js`

- Created a regular function `calculateResult(marks)` to determine whether a learner passed or failed.
- Created an arrow function `displayResult(name, result)` to display the learner's result.
- Stored learner information in an array of objects.
- Used a `for...of` loop to process each learner.

## Task 2: Arrays & Array Methods

**File:** `task2_array_methods.js`

- Used `forEach()` to display every student's details.
- Used `map()` to create an array containing student names.
- Used `filter()` to select students who scored 80 or above.

```bash
node Assignment3.js
```
